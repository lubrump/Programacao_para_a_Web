SI401 - Programação para a Web

Tópicos

A disciplina aborda todo o processo de criação de sites e sistemas para a internet. Ela começa com a elaboração de páginas web usando linguagens de marcação (HTML) para estruturar os conteúdos, e folhas de estilo (CSS) para definir o visual. Em seguida, introduz o JavaScript para adicionar interatividade e dinamismo diretamente no navegador. O curso ensina a geração dinâmica de páginas no servidor (back-end), permitindo processar dados e integrar bancos de dados para criar sistemas personalizados. Por fim, compreende-se o uso de servidores web para hospedar e colocar os projetos no ar, aplicando todo esse ecossistema em atividades práticas de implementação de sistemas reais.

Ementa

Objetivos

O curso tem o objetivo de oferecer uma visão abrangente sobre o ecossistema de programação Web, preparando o aluno para compreender a arquitetura e as demandas do desenvolvimento moderno. A formação visa ainda capacitar o estudante a dominar as principais linguagens de marcação e estilo para a estruturação de interfaces. Além disso, abrange a criação e a execução de scripts no lado do cliente.

Avaliação

A disciplina contará com um Projeto Final (a ser desenvolvido em grupo), dividido em três entregas parciais ao longo do semestre, e uma série de exercícios práticos de fixação (a serem desenvolvidos individualmente). Tais atividades serão utilizadas para avaliar a aprendizagem. No caso do Projeto Final, as notas individuais de cada aluno serão atribuídas conforme sua contribuição em cada etapa.
