# Projetos de Programação para a Web

Este espaço foi criado para centralizar, organizar e documentar todos os projetos, atividades e trabalhos práticos desenvolvidos ao longo do semestre na disciplina de **Programação para a Web**.

O objetivo deste portfólio é registrar minha evolução prática no desenvolvimento web, aplicando desde conceitos fundamentais de estrutura e estilização até o desenvolvimento de aplicações dinâmicas e integração com o back-end.
