# Portfólio de Desenvolvimento Web

Este repositório reúne os projetos, exercícios e trabalhos práticos desenvolvidos ao longo da disciplina de **Programação para a Web**.

O objetivo deste espaço é documentar a evolução técnica e prática no ecossistema web, contemplando desde a estruturação e estilização de páginas até a construção de aplicações dinâmicas e integração com o back-end.

---

## Tecnologias e Ferramentas

Ao longo da disciplina, foram trabalhadas as seguintes tecnologias:

- **Front-end:** HTML5, CSS3, JavaScript (ES6+)
- **Ferramentas:** Git, GitHub, VS Code
